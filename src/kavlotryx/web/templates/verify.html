{{ icon("verified") }}Proof-of-closure flow

policy: strict scope parity
Phase 1 · intake Scanners feed observations

Adapters turn Prowler, Trivy and OCSF files into OCSF 2002/2003/2004 records. Each row is kept as raw JSON.

scope = scanner + account or artifact
Phase 2 · verification Absence proves the fix

A finding is fixed when no source still reports it. A work item whose findings are all fixed closes its ticket with a comment naming the scan.

fixed = no present source left
Phase 3 · regression guard Early closes and returns

A ticket set to Done too early is held in pending_verification. A finding that comes back reopens the same ticket.
